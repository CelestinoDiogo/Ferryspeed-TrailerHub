# Ferryspeed TrailerHub Operational Acceptance Checklist

Use this checklist before a shift or after a deploy. If anything fails, stop and fix it before daily use.

## Vessel Operations

- [ ] I can create or import a vessel list.
- [ ] I can confirm the vessel list.
- [ ] I can mark trailers as arrived.
- [ ] I can continue an in-progress vessel workflow without losing state.
- [ ] I can open a trailer and see the correct current status, position, and history.

## Inspections

- [ ] I can start an inspection for an arrived trailer.
- [ ] I can continue an inspection after leaving and returning.
- [ ] I can complete an inspection.
- [ ] I can record front and rear temperatures.
- [ ] Temperature alerts are visible when readings are out of range.
- [ ] I can record damage findings.
- [ ] I can upload photos.

## Compound

- [ ] I can assign or change a compound position.
- [ ] I can move a trailer without leaving the current workspace.
- [ ] Compound occupancy and KPI counts update correctly.
- [ ] I can review compound history for a trailer.

## Export Operations

- [ ] I can create and advance export allocations.
- [ ] Delivered-empty, waiting-loading, collected-loaded, and undo actions behave correctly.
- [ ] Batch actions work on multiple selected rows.
- [ ] Export report pages print correctly.

## Departures

- [ ] I can confirm a single departure.
- [ ] I can confirm a batch of departures.
- [ ] I can undo a supported departure transition.
- [ ] Departed trailers no longer remain in active compound views.

## Stock Check

- [ ] I can start a stock check session.
- [ ] I can review the summary.
- [ ] I can resolve discrepancies.
- [ ] Reconciliation actions are recorded in history.

## Command Centre

- [ ] I can open the Operations Command Centre.
- [ ] KPIs, rows, and exceptions update correctly.
- [ ] I can open the relevant trailer or vessel workspace from the command centre.

## AI Assistant

- [ ] The assistant answers read-only operational questions.
- [ ] It does not perform write actions.
- [ ] It uses the current page context when available.
- [ ] Voice input degrades safely if unsupported.

## Reports

- [ ] Vessel report generation works from the vessel operation detail page.
- [ ] Report preview is editable before sending.
- [ ] Print output is readable and branded.
- [ ] Email sending requires explicit confirmation.
- [ ] Send history is recorded.

## Mobile Use

- [ ] Core actions are usable at mobile width.
- [ ] Drawers and bottom sheets fit on screen.
- [ ] Buttons have usable tap targets.
- [ ] The current list/workspace state stays visible after an action.
- [ ] Photo capture and upload work on a supported mobile device.
